# Triage labels

The triage skills speak in five canonical roles. This file maps each role to the label string used in OpenVocally's GitHub Issues.

| Role | Label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer needs to evaluate this issue. |
| `needs-info` | `needs-info` | Waiting on the reporter for more information. |
| `ready-for-agent` | `ready-for-agent` | Fully specified, so an agent can work on it without a human. |
| `ready-for-human` | `ready-for-human` | Needs a person to implement it. |
| `wontfix` | `wontfix` | Will not be actioned. |

When a skill names a role, such as "apply the ready-for-agent triage label", apply the label from this table.
